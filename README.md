# Framekit

Alap app videóvágóknak és YouTubereknek: **thumbnail** és **csatorna banner** készítése, YouTube preset méretekkel, PNG exporttal.

## Indítás

```bash
npm install
npm run dev
```

## Ami benne van

- **Thumbnail** (1280×720) és **Banner** (2560×1440) preset
- Formák, szövegrétegek, húzás / átméretezés, sablonok, effektek
- **Mentés / betöltés** (böngésző + JSON export/import)
- **Profil** (felhasználónév, e-mail, telefon, kód) — jelenleg helyi, később szerverre vihető
- **Billentyűparancsok** (⌘Z, ⌘S, …) — `⌘/` a listához
- **Export PNG**

## Sablonok

- Thumbnail: Bold Click, Minimal, Gaming Neon
- Banner: Brand Banner, Cinematic
